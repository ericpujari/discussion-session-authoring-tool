# Discussion Session Authoring Tool

A structured drafting interface for Synthesis session writers to author Discussion
Sessions (ages 8–14) that automatically follow the correct structure, timing, and
tone/sensitivity guardrails.

Not an AI generator — it's a writer's tool, not a content-writing tool.

See `CLAUDE.md` for full project context (read this first if you're Claude Code).

## Structure

- `CLAUDE.md` — project context for Claude Code
- `reference/Discussion_Session_Template.md` — the canonical session spec
- `reference/sessions/` — 9 real deployed sessions, for tone/structure reference
- `reference/session_builder.html` — the existing student-facing drafting tool (separate,
  different audience — kept here for reference/reusable patterns only)
- `docs/` — planning notes, open questions
- `src/` — the actual tool, once we start building it
